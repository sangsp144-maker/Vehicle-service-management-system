# Vehicle Service Management System

A simple Flask based web app to manage vehicle service records.

## Features
- Add Vehicle Details (Number, Owner, Service Type)
- View All Service Records
- Delete Records
- Responsive Design

## How to Run
1. pip install -r requirements.txt
2. python app.py

## Tech Stack
- Python Flask
- HTML, CSS, Bootstrap
